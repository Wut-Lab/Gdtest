1

See how a game is built

Phoneabout 10 minutes

Godot is two things. The engine runs the game: about 60 times a second it reads the buttons, moves everything, checks what bumped into what, and draws the screen. The editor is the app you use to build the game. You'll meet the editor in step 2; this step is about the idea underneath everything.

The one big idea: everything is a tree of nodes. A node is a small part that does one job: a hitbox, a camera, a picture, a sound. You stack nodes into a tree, and a saved tree is called a scene. Scenes can sit inside other scenes, so a whole game is scenes made of scenes.

Explore Square Hop's player

This is the real tree from scenes/player.tscn. Tap each node to see what it does.

The whole game is the same idea, one level up. The Main scene holds the sky, the level, the HUD (timer, menus, Tune button) and the touch buttons. The level holds the tiles, the start point, the goal, the teleporters and the player.

2

Get Godot running

Computerabout 15 minutes, once

To see your game the way Godot sees it, you need the editor on a computer. It's free, it's one app, and Square Hop opens in it like any Godot project. You only do this once.

On a phone? Godot's editor is also available for Android, through the Google Play Store. It works, but it's cramped on a phone screen and better on a tablet. There's no iPhone version, so on an iPhone, use a computer for this step.

Your tasks Computer

Find your way around the editor

The editor has a lot of buttons, but you only need five areas to start.

  • 1Scene shows the tree of the scene you have open, like the explorer in step 1. Click a node to select it.
  • 2FileSystem lists every file in the project. Double-click a .tscn file to open that scene.
  • 3The main view shows the scene. The tabs above it switch between 2D, 3D and the Script editor.
  • 4Inspector shows the settings of whatever node you selected. This is where you change things without writing code.
  • 5Play buttons. ▶ runs the whole game (F5). The others run just the scene you have open, or stop the game.
3

Change something and see it

ComputerPhoneabout 10 minutes

Most of making a game is this loop: change a setting, play, notice how it feels, change it again. In Godot, a node's settings live in the Inspector. Square Hop's player has its feel there: run speed, jump strength, gravity, how bouncy rubber is.

Settings are just numbers with a meaning. In scripts/player.gd, a line like @export var jump_velocity := 760.0 does two things: it gives the player a jump strength of 760, and the word @export makes it show up in the Inspector so you can change it without touching code. Your in-game Tune panel shows the very same numbers.

Try it here first

Drag the sliders to see how jump strength and gravity work together. The math is the same as in the game.

760
2200
Jump height 4.1 tiles Time in the air 0.69 s Distance at full run 5.4 tiles

Notice that doubling jump strength makes you jump four times as high, while doubling gravity halves it. Level design depends on this: a wall 5 tiles tall needs a jump of more than 5 tiles, which is why level 1 gives you rubber there.
