A beginner's path in Godot

Learn Godot with Rock Drift

For complete beginners. You'll build a small space game: a ship that turns, thrusts and drifts while rocks float past. Each step adds one piece and teaches one idea. Tick tasks off as you go; your progress is saved on this device.

Before you start

  • No experience needed. You don't need to know how to code. You'll copy short pieces of code, run them, then read what they mean in plain English.
  • You won't understand every line at first, and that's normal. Getting it working comes first; understanding grows with each step.
  • What you need: this page on your phone for reading, and for steps 2 and 3 a Windows, Mac or Linux computer with a keyboard and mouse. Godot is free and about 150 MB.
  • How long: step 1 takes about 10 minutes. Steps 2 and 3 take 30 to 45 minutes each the first time. Do one step per sitting if you like; your ticks are saved.
  • Getting the code onto your computer: open this same page on the computer (you're signed in to Claude there too) and use the Copy buttons. That's easier than typing it.
Words you'll meet (tap to open)
Game engine
The program that runs a game for you: it draws the screen, reads the controls, and moves things. Godot is a game engine.
Editor
The app where you build the game: the Godot window with all its panels.
Project
One game's folder, holding all its files.
Node
One building block with one job, like "a hitbox" or "a camera".
Scene
A group of nodes arranged in a tree and saved as a file ending in .tscn. The ship is a scene; so is a rock.
Instance
A copy of a scene placed inside another scene. The game has five instances of the rock scene.
Script / code
Written instructions for a node, in a file ending in .gd. Godot's language is called GDScript.
Variable
A named box that holds a value, like velocity or thrust. Its value can change while the game runs.
Function
A named set of instructions, starting with func. Godot runs some by itself, like _ready and _process.
Frame
One update of the screen. Games run about 60 frames a second, and the code runs once per frame.
Position
Where something is, as two numbers: x (how far right) and y (how far down). The top-left corner of the screen is 0, 0.
Velocity
Speed plus direction: how far something moves each second, and which way.
Signal
A message a node sends when something happens, like "something touched me". Other code can listen for it.
Inspector
The panel on the right of the editor that shows the settings of whatever you selected.
res://
Godot's name for your project folder. res://ship.gd means "ship.gd in this project".
1

Plan the game

Phoneabout 10 minutes

Here's what you'll have at the end of step 3. Hold Thrust to push forward and the arrows to turn. Notice that the ship keeps drifting after you let go, and that flying off one edge brings you back on the other. Touch a rock and the round starts over.

On a keyboard: arrow keys, after tapping the game once.

Godot is two things. The engine runs the game: about 60 times a second it reads the controls, moves everything, checks what's touching what, and draws the screen. The editor is the app where you build the game. You'll meet it in step 2.

The one big idea: everything is a tree of nodes. A node is a small part with one job: a body, a hitbox, a camera, a sound. You put nodes together into a tree, and a saved tree is a scene. Scenes can be placed inside other scenes, like the ship and rocks inside the main scene.

2

Make the ship fly

Computerabout 30 to 45 minutes

Now you'll install Godot, start a project, and build the ship: one scene with two nodes, plus a script that makes it turn, thrust and drift.

On a phone? Godot's editor is available for Android through the Google Play Store. It works, but it's cramped on a phone and better on a tablet. There's no iPhone version, so use a computer for steps 2 and 3. You can still read them on your phone first.

Get Godot

  1. On your computer, open godotengine.org/download in a web browser. The page detects whether you're on Windows, Mac or Linux.
  2. Click the download for Godot Engine (version 4.6 or newer). Don't pick the one marked .NET; that's for a different programming language.
  3. Windows: the download is a zip file. Open it and drag the Godot app out to your Desktop, then double-click it. If Windows shows "Windows protected your PC", click More info, then Run anyway. That warning is common for apps downloaded from the web.
    Mac: open the download and drag Godot into your Applications folder, then open it. If your Mac says it can't be opened, right-click it, choose Open, then Open again.

The Godot Project Manager: a window listing your projects. It's empty for now.

Start a project

  1. Click Create (top left of the Project Manager).
  2. In Project Name, type Rock Drift.
  3. For Project Path, click Browse and choose a place you'll find again, like Documents. Godot makes a Rock Drift folder there.
  4. Under Renderer, choose Compatibility. The renderer is the part that draws the game; Compatibility works on the most devices, including phones and web browsers.
  5. Click Create (it may say Create & Edit).

The Godot editor: panels on the left and right, and a big area in the middle, which may show a 3D grid. That's fine; it switches to 2D when you add your first node.

Find your way around

  • 1Scene: the node tree of the scene you have open. The + button adds a child node.
  • 2FileSystem: your project's files. Double-click one to open it.
  • 3Main view: shows the scene. The tabs above it switch to the Script editor.
  • 4Inspector: the settings of the selected node.
  • 5Play buttons: run the whole game (F5) or just the scene you have open (F6).

Build the ship scene

  1. In the Scene panel (top left), under Create Root Node, click Other Node. A window with a long list of node types opens.
  2. Type Area2D in the search box at the top, click Area2D in the list, then click Create.

Area2D in the Scene panel, with a small yellow warning triangle. The warning says it has no shape yet; you'll fix that in a moment.

  1. Double-click the word Area2D, type Ship, and press Enter to rename it.
  2. With Ship highlighted, click the + button at the top of the Scene panel (Add Child Node). Search for CollisionShape2D and click Create.

CollisionShape2D indented under Ship, which means it belongs to the ship. It has a warning too.

  1. Keep CollisionShape2D selected. In the Inspector on the right, find Shape, which says <empty>. Click it and choose New CircleShape2D.
  2. Click the word CircleShape2D that appeared, to open its settings. Set Radius to 12 and press Enter.

A small blue circle in the middle of the view, and the warning triangles are gone.

  1. Save: press Ctrl+S (Cmd+S on a Mac). A save window opens with the name ship.tscn filled in. Click Save.
  2. Right-click Ship (the top node, not CollisionShape2D) and choose Attach Script. In the window that opens, leave everything as it is (Language: GDScript, Path: res://ship.gd) and click Create.

The middle area switches to the Script view, showing a few lines of starter code, and ship.gd appears in the FileSystem panel.

  1. Click inside the code. Press Ctrl+A to select it all and Delete to remove it.
  2. Tap Copy on the code below, click back in Godot's script area, and paste with Ctrl+V (Cmd+V on a Mac). Save with Ctrl+S.

How to read code

  • Godot reads a script from top to bottom.
  • Lines starting with # are notes for people. Godot skips them, so they're where the explanations are.
  • var makes a variable: a named box holding a value, like velocity.
  • func starts a function: a named set of instructions. Godot runs _ready once at the start and _process every frame.
  • Lines pushed to the right (indented with a Tab) belong to the line above them that ends with a colon :.
ship.gd
extends Area2D
# This script tells the ship what to do. Lines starting with # are notes
# for people: Godot skips them.

# Settings. @export also shows them in the Inspector, so you can change them there.
@export var turn_speed := 3.5   # how fast it turns
@export var thrust := 400.0     # how hard the engine pushes
@export var max_speed := 500.0  # top speed
@export var drag := 40.0        # how quickly it slows down when coasting

# The ship's speed and direction right now. It starts at zero: not moving.
var velocity := Vector2.ZERO


# Godot runs _ready once, when the ship first appears.
func _ready() -> void:
	position = get_viewport_rect().size / 2   # start in the middle of the screen


# Godot runs _process every frame, about 60 times a second.
# delta is how many seconds passed since the last frame (about 0.016).
func _process(delta: float) -> void:
	# Turn with left and right.
	var turn := Input.get_axis("ui_left", "ui_right")
	rotation += turn * turn_speed * delta

	# Push forward with up, or slowly coast to a stop.
	if Input.is_action_pressed("ui_up"):
		velocity += Vector2.RIGHT.rotated(rotation) * thrust * delta
	else:
		velocity = velocity.move_toward(Vector2.ZERO, drag * delta)
	velocity = velocity.limit_length(max_speed)
	position += velocity * delta   # move by this frame's share of the velocity

	# Leave one edge of the screen, come back on the other.
	var screen := get_viewport_rect().size
	position.x = wrapf(position.x, 0.0, screen.x)
	position.y = wrapf(position.y, 0.0, screen.y)
	queue_redraw()   # ask Godot to run _draw again, so the flame shows up


# Draws the ship: a pointed shape, plus a flame while thrusting.
func _draw() -> void:
	var body := PackedVector2Array([Vector2(16, 0), Vector2(-12, -10), Vector2(-6, 0), Vector2(-12, 10)])
	draw_colored_polygon(body, Color("ff6b5e"))
	if Input.is_action_pressed("ui_up"):
		var flame := PackedVector2Array([Vector2(-7, -4), Vector2(-18, 0), Vector2(-7, 4)])
		draw_colored_polygon(flame, Color("ffd23f"))

No red text at the bottom of the script area. If there is, see "Something not working?" further down.

  2. Use ↑ to thrust and ← → to turn. If the keys do nothing, click inside the game window first.

A new dark window with your red ship in the middle. It drifts after you let go of thrust, and wraps around the edges.

What the code says

@export var thrust := 400.0
A setting with a starting value. @export also shows it in the Inspector, so you can change it there without touching the code.
func _process(delta)
Godot calls this every frame. delta is how many seconds passed since the last frame, so movement is the same speed on fast and slow computers.
velocity += ... * thrust * delta
Thrust doesn't move the ship directly. It changes the velocity (speed and direction), and velocity moves the ship. That's why it keeps drifting.
wrapf(position.x, 0.0, screen.x)
If the ship goes past an edge, put it back on the opposite side.
func _draw()
Draws the ship as a shape, plus a flame while you're thrusting. No picture file needed.

3

Add rocks and crashing

Computerabout 30 to 45 minutes

Now you'll make a rock scene, a main scene that brings the ship and five rocks together, and a crash that starts the round over. Along the way you'll use two of Godot's most important ideas: instancing and signals.

Instancing: one scene, many copies. You build the rock once. The main scene then makes five copies of it, called instances. Change rock.tscn and every rock changes.

Signals: "this just happened." Nodes announce events, and other code can listen. An Area2D announces area_entered when another area touches it. The ship listens for that and crashes.

Build the rock

You'll build the rock the same way as the ship.

  1. At the very top left of the editor, open the Scene menu and choose New Scene. A new empty tab opens.
  2. Click Other Node, search for Area2D, and click Create. Double-click it and rename it Rock.
  3. With Rock selected, click +, add a CollisionShape2D, and in the Inspector set its Shape to New CircleShape2D. Click it and set Radius to 30 this time.
  4. Save with Ctrl+S as rock.tscn.
  5. Right-click Rock, choose Attach Script, and click Create (the path should say res://rock.gd).
  6. Select all of the starter code, delete it, paste the code below, and save.
rock.gd
extends Area2D
# This script makes one rock drift, spin and draw itself.

@export var speed := 80.0    # how fast it drifts
@export var radius := 30.0   # how big it is

var velocity := Vector2.ZERO           # speed and direction
var spin := 0.0                        # how fast it turns
var outline := PackedVector2Array()    # the corner points of its lumpy shape


func _ready() -> void:
	# Pick a random direction and spin, and a lumpy rock shape.
	velocity = Vector2.from_angle(randf() * TAU) * speed
	spin = randf_range(-1.5, 1.5)
	for i in 10:
		var angle := TAU * i / 10
		outline.append(Vector2.from_angle(angle) * radius * randf_range(0.75, 1.1))


# Every frame: move, spin, and wrap around the screen edges.
func _process(delta: float) -> void:
	position += velocity * delta
	rotation += spin * delta
	var screen := get_viewport_rect().size
	position.x = wrapf(position.x, -radius, screen.x + radius)
	position.y = wrapf(position.y, -radius, screen.y + radius)


func _draw() -> void:
	draw_colored_polygon(outline, Color("8a8fa8"))

Press F6: a grey lumpy rock drifts out from the top-left corner, spinning. It starts in the corner because its position is 0, 0; the main scene will place rocks properly. Each run picks a new direction and shape.

Build the main scene

  1. Open the Scene menu, choose New Scene, and this time click 2D Scene. That makes a Node2D, a plain node with a position. Rename it Main.
  2. In the FileSystem panel (bottom left), find ship.tscn. Drag it up and drop it on the word Main in the Scene panel.

Ship indented under Main, with a small icon beside it showing it's an instance (a copy of your ship scene), and the red ship in the view.

  1. Save with Ctrl+S as main.tscn.
  2. Right-click Main, choose Attach Script, and click Create (res://main.gd). Replace the starter code with this, and save:
main.gd
extends Node2D
# The main scene's script: it adds the rocks when the game starts.

# Load the rock scene once, so we can make copies of it.
const ROCK := preload("res://rock.tscn")


func _ready() -> void:
	# Place 5 rocks in a ring around the middle, away from the ship.
	var middle := get_viewport_rect().size / 2
	for i in 5:
		var rock := ROCK.instantiate()
		rock.position = middle + Vector2.from_angle(randf() * TAU) * 260
		add_child(rock)
const ROCK := preload("res://rock.tscn")
Loads the rock scene once and calls it ROCK, ready to copy. const is like var, but for a value that never changes.
for i in 5:
A loop: do the indented lines below it five times.
ROCK.instantiate() · add_child(rock)
Make a new copy of the rock, then put it into the main scene so it appears.

Make the ship crash

  1. In the FileSystem panel, double-click ship.gd. It opens in the Script view.
  2. Select all of it, delete it, paste this new version, and save. The highlighted lines are the new ones; everything else is the same as before.
ship.gd
extends Area2D
# This script tells the ship what to do. Lines starting with # are notes
# for people: Godot skips them.

# Settings. @export also shows them in the Inspector, so you can change them there.
@export var turn_speed := 3.5   # how fast it turns
@export var thrust := 400.0     # how hard the engine pushes
@export var max_speed := 500.0  # top speed
@export var drag := 40.0        # how quickly it slows down when coasting

# The ship's speed and direction right now. It starts at zero: not moving.
var velocity := Vector2.ZERO
var crashed := false   # becomes true once we hit a rock


# Godot runs _ready once, when the ship first appears.
func _ready() -> void:
	position = get_viewport_rect().size / 2   # start in the middle of the screen
	area_entered.connect(_on_area_entered)


# Godot runs _process every frame, about 60 times a second.
# delta is how many seconds passed since the last frame (about 0.016).
func _process(delta: float) -> void:
	# Turn with left and right.
	var turn := Input.get_axis("ui_left", "ui_right")
	rotation += turn * turn_speed * delta

	# Push forward with up, or slowly coast to a stop.
	if Input.is_action_pressed("ui_up"):
		velocity += Vector2.RIGHT.rotated(rotation) * thrust * delta
	else:
		velocity = velocity.move_toward(Vector2.ZERO, drag * delta)
	velocity = velocity.limit_length(max_speed)
	position += velocity * delta   # move by this frame's share of the velocity

	# Leave one edge of the screen, come back on the other.
	var screen := get_viewport_rect().size
	position.x = wrapf(position.x, 0.0, screen.x)
	position.y = wrapf(position.y, 0.0, screen.y)
	queue_redraw()   # ask Godot to run _draw again, so the flame shows up


# Something touched the ship: crash, and start the round again.
func _on_area_entered(_area: Area2D) -> void:
	if crashed:
		return   # already crashed: ignore any more hits
	crashed = true
	get_tree().reload_current_scene.call_deferred()   # wait until the collision check is done


# Draws the ship: a pointed shape, plus a flame while thrusting.
func _draw() -> void:
	var body := PackedVector2Array([Vector2(16, 0), Vector2(-12, -10), Vector2(-6, 0), Vector2(-12, 10)])
	draw_colored_polygon(body, Color("ff6b5e"))
	if Input.is_action_pressed("ui_up"):
		var flame := PackedVector2Array([Vector2(-7, -4), Vector2(-18, 0), Vector2(-7, 4)])
		draw_colored_polygon(flame, Color("ffd23f"))
area_entered.connect(_on_area_entered)
Listen for a signal: "when another area touches me, run the function _on_area_entered."
if crashed: return
Two rocks can touch you at the same moment. This makes sure the round only restarts once. return means "stop this function here".
reload_current_scene.call_deferred()
Start the scene over from the beginning, but wait until Godot finishes checking for collisions this frame. Godot doesn't allow removing things in the middle of that check.

Play the whole game

  1. Click the main.tscn tab at the top of the view, then press F5 (or the ▶ play button at the top right). F5 runs the whole game, not just the open scene.
  2. The first time, Godot asks which scene the game should start with. Click Select Current, which picks main.tscn.

Something not working?
